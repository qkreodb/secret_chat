# 🔒 Secret LAN Chat

외부 서버 없이 **같은 네트워크(LAN)** 안에서 비밀리에 대화하는 데스크톱 채팅 앱입니다.
한 명이 방장(서버)이 되고 나머지는 클라이언트로 접속합니다. (Electron + Node `net`/`dgram`)

## 주요 기능

| 요구사항 | 구현 |
|---|---|
| REQ-001 | 가입 없이 사용자 이름만 입력하고 진입 |
| REQ-002 | 방 개설 시 방 이름·비밀번호 필수, '목록에서 숨김'(비공개) 옵션 |
| REQ-003 | UDP 브로드캐스트로 같은 대역의 **공개방** 자동 탐색 |
| REQ-004 | 비공개방은 방장 IP·포트·비밀번호로 직접 입장 |
| REQ-005 | 내 메시지 오른쪽 / 상대 메시지 왼쪽 + 이름 표시 (버블 UI) |
| REQ-006 | 우측 사이드바에 실시간 접속자 명단 (입/퇴장 갱신) |
| REQ-007 | 📌 항상 위에 표시 토글 (기본 꺼짐) |
| REQ-008 | 투명도 슬라이더 20%~100% |
| REQ-009 | 닫기/최소화 시 트레이로 숨김, 백그라운드 수신 시 Windows Toast 알림, 트레이 더블클릭으로 복구 |

## 보안 / 동작 방식

- 비밀번호는 SHA-256 해시로 검증하며, **틀리면 입장 전에 즉시 차단**됩니다.
- **비공개방**은 UDP 탐색에 일절 응답하지 않으므로 같은 LAN이라도 목록에 뜨지 않고,
  방장 IP·포트·비밀번호를 모르면 접속할 수 없습니다.
- 모든 통신은 LAN 내부 TCP/UDP만 사용합니다. **인터넷이 차단된 환경에서도 동작**합니다.

> 참고: 메시지 본문 자체는 평문 TCP로 전송됩니다. 패킷 캡처 수준의 보안이 필요하면
> 추후 TLS(자체 서명) 또는 공유키 AES 암호화를 추가할 수 있습니다.

## 포트

- UDP `47654` : 방 탐색(브로드캐스트)
- TCP `47655~` : 채팅 (사용 중이면 자동으로 다음 포트 사용 — 방장 화면 상단에 실제 포트 표시)

방화벽에서 위 포트의 사설망(Private) 인바운드를 허용해야 다른 PC가 접속할 수 있습니다.

## 실행

```powershell
npm install
npm start
```

## 배포용 설치 파일(.exe) 만들기

```powershell
npm run dist
```
`dist/` 폴더에 NSIS 설치 파일이 생성됩니다.

## 같은 PC에서 테스트

방장 인스턴스를 띄운 뒤, 다른 PC에서 방장 화면에 표시된 IP·포트·비밀번호로 입장하세요.
(단일 인스턴스 잠금이 걸려 있어 한 PC에서는 창이 하나만 뜹니다. 2대 이상의 PC로 테스트하세요.)
